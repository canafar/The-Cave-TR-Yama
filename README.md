# The Cave Türkçe Yama

Windows Steam sürümü için Türkçe metin yaması.

## İndirme
Yamayı bu deponun Releases bölümünden indirebilirsiniz.

## Kurulum
1. Oyunu kapatın ve orijinal dosyaları yedekleyin.
2. ZIP içindeki Data ve Win klasörlerini Cave.exe'nin
   bulunduğu oyun klasörüne kopyalayın.
3. Dosyaları değiştirmeyi onaylayın.
4. Steam'de oyun dili İngilizce kalsın.
5. Oyun ayarlarından altyazıları açın.

## Bilinen sorunlar
- Bazı tabela ve afişler İngilizce kalabilir.
- ğ harfi g gibi görünebilir.
- Seslendirme İngilizcedir.

Temiz Windows Steam kurulumunda çalıştığı test edildi.
